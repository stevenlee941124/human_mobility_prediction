# HuMob 2026: 歷史基線算法探索存檔 (Historical Baseline Archive)

本資料夾歸檔了在抵達最終 **SOTA v3 (每週波峰波谷中點飽和阻尼基線)** 之前，於研究過程中所歷經的先導探索版本。

---

## 版本演進一覽

| 歷史版本檔案 | 演進階段 | 核心嘗試與特點 | 侷限與演化原因 |
| :--- | :--- | :--- | :--- |
| **`per_route_adaptive_baseline.py`** | **v0 原型版** | 純自適應滑動平均與平滑濾波。 | 無法感知震後衝擊行為模式，在盲區容易產生無效震盪。 |
| **`per_route_exponential_baseline.py`** | **v1 初版** | 首次導入指數衰減/阻尼微分方程來銜接 2~3 月 60 天盲區。 | 固定阻尼係數，未細分災後路線是復甦、消散還是避難。 |
| **`per_route_exponential_baseline_v1_sota.py`** | **v1 改進版** | 引入震前震後錨點統計，初步優化阻尼係數估算。 | 仍以全局單一經驗公式擬合，難以兼顧不同空間特徵。 |
| **`per_route_exponential_baseline_v2_stratified.py`** | **v2 分層版** | **首次提出 9 類災後復甦分層體系** (Class 1~9)。 | 每週錨點採用「週平均值（Mean）」，在通勤路線上容易受週六週日低谷影響而被向下拉偏。 |
| *(當前生效版本)*<br/>👉 `pipeline/src/per_route_sota_v3_baseline.py` | **v3 SOTA 當前版** | 改採**每週「波峰波谷中點（Midpoint: 0.5 * (max + min)）」**作為純淨中軸錨點，徹底消弭基線下移偏差，結合 52.7% 全零硬隔離與四月平衡值，成為最終採用的物理宏觀基線。 | **已移入 `pipeline/src/` 作為主管線核心模組運行**。 |
